# Iris to Id: Visual Novel Maker Plugins

A collection of bug fixes and new features for Visual Novel Maker. Free to use under MIT license.

## Bug Fixes

- **Cursor Fix** — Addresses custom cursors not displaying properly after loading saves and ensures persistence when opening/closing menus.
- **Window Resize Fix** — Corrects ratio/stretch display feature breaking after window maximize/restore cycles.
- **White Outline Fix** — Eliminates white outline artifacts on character sprites during zoom-out.
- **Template_Backlog Fix** — Replaces the original backlog with word-wrapping and mouse control support.

## New Features

- **Backlog (Message History)** — HTML/CSS customizable display supporting VNM text codes, character message merging, and mouse wheel scrolling.
- **Text Input** — Customizable dialog for player name entry and other inputs, storing results in string variables.
- **Letter Sounds** — Per-letter sound effects for messages, adding emotional depth and audio feedback.
